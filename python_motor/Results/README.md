# Saved motor experiments

This folder may contain results from earlier versions of the combined GUI.
The current GUI asks whether to save after each run and lets you choose the
destination. It does not automatically write into this folder.

1. Follow the [combined GUI guide](../README.md) to acquire a test.
2. At the end, choose Yes to save and select a destination and filename.
3. The CSV contains only time, resistance, relative resistance (%), and
   displacement. The protocol is included in the suggested filename.
   No companion files are generated by the current version.
4. To plot the two resistance/time graphs, run from the project root:

```powershell
.\.venv\Scripts\python.exe python_motor/plot_sensor_test.py
```

5. Select the main measurement CSV, not the motor-events CSV. The live combined
   GUI provides the resistance-versus-displacement graph.

Demo experiments have a `DEMO_` prefix in the suggested filename. Time is in
seconds, resistance in ohms, estimated displacement in millimetres, and
relative resistance in percent. See the parent guide for synchronization
limits and Excel decimal-locale import instructions.
