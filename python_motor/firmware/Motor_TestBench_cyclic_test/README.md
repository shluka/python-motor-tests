# Motor cyclic-test sketch

1. Open `Motor_TestBench_cyclic_test.ino` in Arduino IDE.
2. Select the Mega board and its COM port.
3. Verify the motor calibration, then compile and upload.
4. Close Serial Monitor before connecting the combined GUI.

See [firmware preparation](../README.md) for calibration and connection steps,
and [GUI instructions](../../README.md) to configure and run a test.
