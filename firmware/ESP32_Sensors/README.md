# Upload this sketch to the ESP32-S3

1. Open `ESP32_Sensors.ino` in Arduino IDE.
2. Select your ESP32-S3 board and its COM port.
3. Close applications using that port, then compile and upload.
4. Check output at 115200 baud if needed, then close Serial Monitor.
5. Follow the [full wiring and firmware instructions](../README.md) and launch
   the [Python GUI](../../python/README.md).
